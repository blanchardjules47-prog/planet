# Planet Explorer

Un petit jeu de survie sur une planète inconnue.

## Objectif
- Collecter 8 cristaux d'énergie.
- Éviter les tempêtes.
- Retourner à la base pour terminer la mission.

## Contrôles
- Flèches ou ZQSD

## Comment lancer le jeu
1. Ouvre le fichier `index.html` dans un navigateur.
2. Le jeu démarre automatiquement.
